蘇清的 Viewpoint 模型资源 / SuQing's Viewpoint Model Resources

适用 Build 42.22.2 与 Project Viewpoint 0.1.7 单人游戏。将这个配套模组加入主菜单的默认启用列表，重启后按 Delete，进入 Graphics（图像）的 Resource Packs（资源包），分别启用传送门和返鲜冰箱。主模组按原有存档名单启用。进档后查看现有物件的三维外观，切回等距视角核对精灵和交互。

For single-player Build 42.22.2 with Project Viewpoint 0.1.7. Enable this companion mod in the main-menu default list and restart. Press Delete, open Graphics > Resource Packs and activate the portal and fridge packs individually. Keep the gameplay mods enabled in the target save. Check the 3D models in an existing save, then switch to isometric view to verify the sprites and interactions.
