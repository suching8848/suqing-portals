# 蘇清的传送门行程保护 / SuQing's Portal Travel Guard

适用于已核验的 B42.22.2、PZ Optimization 及 ZombieBuddy 2.3.4 单人组合。关闭 Debug 时，传送门需要本补丁。仅在本地玩家实际传送期间临时改变防撞、丧尸识别、下坠和已核对的攻击及火焰处理。角色已有的作弊标记、伤口和着火状态保留。补丁缺失或关键接口未启用时，传送门会在扣电前拒绝新请求。

完成传送或退回并处理结算后再退出、停用补丁。若存档仍有待处理行程，保留原角色和电池状态，安装同版本补丁后通过传送门的恢复入口继续。游戏内跨地图分块、危险落点和保存重进由玩家验收。

For the verified single-player combination of B42.22.2, PZ Optimization and ZombieBuddy 2.3.4. Portals use this add-on to travel with Debug off. It changes collision, zombie detection, falling, and audited hit and fire responses for the travelling local player for the duration of a transfer. Existing cheat flags, wounds and burning states are preserved. If the add-on or its required checks are unavailable, new transfers stop before battery charge is deducted.

Finish the transfer or complete the return and settlement before exiting and disabling the add-on. Re-enable the same version to resume recovery from a pending transfer. Cross-chunk travel, hazardous arrivals and restoration after loading a save still require in-game testing.
