## 使用与建造

建造两座固定传送门，右键门体打开管理界面，命名并从列表选择另一座门完成双向配对。每门配有四个独立原版汽车电池槽，接收`Base.CarBattery1/2/3`；电池可安装、取回和反复充电。

每座门消耗小金属板8、金属管4、电线8、电子零件16、高端相机1、手持对讲机1，要求电工4级、焊接3级。接受原版六种手持对讲机，含自制款；收音机和大型电台不可替代。完好的螺丝刀、焊枪和焊接面罩为保留工具，本版不额外扣焊枪燃料或焊条。汽车电池在建成后另装。原生建造逻辑处理材料、技能与取消建造；已有门不补扣新配方材料。

每次传送只从**出发门**已安装电池扣电，沙盒范围0.5～4块满电汽车电池等量，默认2。四块全满在耗电0.5／2／4时分别可出发8／2／1次。**到达门无需电池或当地供电**；返程前该门仍需足够出发电量。电池本身不会作为传送材料消耗。

可缩放管理窗口采用紧凑2×2四槽，显示电池名称、耐久、电量、配对、可传送次数、电源来源与充电状态。常见分辨率以一屏展示为目标，小窗口或大字体保留必要滚动，传送按钮固定在底部。领取物资菜单、发放代码和对应沙盒开关已移除，人物物资与技能由正常游戏获得。

门体四朝向随实际四槽安装情况显示十六种电池组合，共64张标准128×256图片与对应Viewpoint模型。封面采用已选C「雨夜归途」；现有icon沿用。

## 充电与能源结算

沙盒只有两项：单次传送耗电量0.5～4、默认2；整门每游戏小时充电量0.05～4、默认0.5。充电速率是**整门总量**，不是每槽各充同样数量。四块空电池在默认速率及足够供电下需8游戏小时充满，补回默认一次传送所需2等量需4游戏小时。

只在门所在区域已加载、当地供电可核实且有完好未满电池时充电。室内市电优先，其余情况只向选定的一个覆盖来源结算。空槽、满电、损坏电池、传送锁定、区域卸载或失去供电时没有本门附加消费；离线及卸载间隔不追补。

- **普通发电机：**按实际成功充入量独立扣油，每满电等量为`0.3 L × GeneratorFuelConsumption`。默认速率0.5、原版默认倍率0.1时，额外消费为**0.015 L/游戏小时**；发电机自身及其他设备油耗另计。燃油不足限制本次充入量。
- **可选Immersive Solar Arrays 1.2.15：**工坊`3781944805`、Mod ID `ISA`，从选定银行的真实原电池储能结算，不把太阳能代理发电机当燃油机扣油。未安装ISA时普通发电机仍可使用。仅支持已核对的1.2.15；未知版本、接口无法核实或`ISA-Fix`组合拒绝桥接，不凭当地通电免费补电。另一个`Immersive Solar Arrays [BETA]-Fix / 3592668881`不在支持范围内。
- **可选 Live Wire 1.7.2。** 启用工坊 `3821807453` 的 `batman_LiveWire` 后，门可从正在供电的逆变器网络中提取已加载电池柜的真实储能。室内市电、独立发电机和受支持的 ISA 电源优先。门的设备回路须开启，挂接 Live Wire 备用发电机的网络以及没有可用电池柜的网络会暂停这条充电路径。具体换算和限制见下方说明。
- **面板与估算：**发电机面板显示额外传送门负载及合计；没有把门注册进Java原生设备清单，不改写原生总负载或ISA `updateDrain`，避免重复计费。BGI等仅读原生总负载的剩余时间估算可能偏长，仍未合入这份独立消费；以实际燃油／储能变化为准。

详见[供电兼容说明](docs/供电兼容说明.md)。

## 保存、停用与范围

支持同一世界内的人物及随身物品；**不支持车辆、拖挂和联机**。原电池保存在门的原生内部存储中，保留身份、耐久、电量、名称及自定义数据。四槽界面负责操作，普通容器按钮、拖放和附近制作入口被隔离；任意第三方直接扫描世界物品不在这些原生界面拦截范围内。

固定门拆除会解除配对并释放原电池；一般家具搬运不受支持。停用前先取回电池并解除配对。schema3保存格式保持；0.1.0旧门可就地接管原存储，异常数据或未完成传送会保留原存储并阻止迁移。若另有0.1.1 Java版安装电池的世界，需先在对应旧版环境取回原电池再升级；纯Lua版不解码、清空或仿造这些不透明物品记录。

传送核实终点身份及出口后完成，失败按原电池票据返回和退款。源区未加载或原电池被外部移走时保留恢复记录，使用右键恢复入口重试；不伪造新电池。世界、人物与区块不是跨文件原子事务，极端断电或存档损坏的一致性仍有限制。异常时保存日志，不要直接清理世界数据。
