# 蘇清的传送门 / SuQing's Portals 0.1.4

本轮发布准备中。沿用工坊3834693880及实时公开可见性0；完成状态以新上传/Git/部署回执为准。

建造、命名并配对四槽汽车电池传送门。单次耗电0.5～4、默认2，全部出发端承担；接收端无需电池或供电。可缩放管理界面显示电源来源和充电状态，普通发电机按实际充入量独立扣油，可选兼容Immersive Solar Arrays 1.2.15真实储能结算。纯Lua，B42.21单人；用户已反馈本轮游戏内测试全部正常。车辆、拖挂和联机不支持，BGI原生负载时间估算可能偏长。

Build named, paired portals with four reusable car-battery slots. Trip cost 0.5–4, default 2, is paid entirely at departure; arrival needs no battery or power. Resizable management identifies power and charging state. Fuel generators pay independently for charge actually stored, with optional real-storage settlement for Immersive Solar Arrays 1.2.15. Pure Lua for B42.21 single-player; the user reported current gameplay tests working normally. Vehicles, trailers and multiplayer are unsupported. BGI/native-load-only time estimates may run long.

This release is being prepared for existing public Workshop item 3834693880, retaining visibility 0. Completion follows new upload/Git/deployment receipts.
